# HomeLedger

A digital record of everything important about your house, as an iPhone and Android app.

- Register your home
- Add appliances and equipment
- Record installation dates and warranties
- Upload receipts and contractor invoices (files, or photos from the camera)
- Track maintenance and repair history
- See upcoming maintenance tasks
- Get reminders for maintenance tasks and warranty expirations

The app is a web app (Vite, plain JavaScript) packaged for iOS and Android with [Capacitor](https://capacitorjs.com).
Data stays on the phone: app data in on-device preferences, receipts as files in the app's private storage.
Reminders are local notifications scheduled on the device, so they work offline and need no server or account.

## Project layout

| Path | What it is |
| --- | --- |
| `src/main.js` | The app: views, forms, state |
| `src/native.js` | Storage, files, camera, share and notification calls (Capacitor on phones, browser fallbacks on the web) |
| `src/lib/reminders.js` | Pure function that turns your data into a list of reminders (unit tested) |
| `src/lib/dates.js` | Date and formatting helpers |
| `android/`, `ios/` | Native projects generated by Capacitor |
| `assets/` | Icon and splash artwork; regenerate with `npx capacitor-assets generate --ios --android` |

## Develop

```bash
npm install
npm run dev        # browser, http://localhost:5173
npm test           # reminder planner tests
```

## Build for Android

Needs Android Studio (or the Android SDK) and JDK 17.

```bash
npm run android    # builds the web app, syncs, opens Android Studio; press Run
```

Without a local setup, open the repo's **Actions** tab, run the **Android** workflow, and download the `homeledger-debug-apk` artifact. Copy it to a phone and open it to install (allow installs from your browser or Files app when asked).

To publish on Google Play you need a Play Console account (one-time $25) and a signing key. Add these repository secrets, then push a tag such as `v1.0.0` to get a signed `.aab` to upload:
`ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`.

## Build for iOS

Needs a Mac with Xcode 15 or later and CocoaPods.

```bash
npm install
npm run ios        # builds the web app, syncs, runs pod install, opens Xcode
```

In Xcode, select the **App** target, open **Signing & Capabilities**, choose your Apple ID team, then press Run with your iPhone connected. A free Apple ID installs the app for 7 days at a time.
To use TestFlight or publish on the App Store you need the Apple Developer Program ($99 per year): Product > Archive, then Distribute App.

The **iOS** GitHub workflow only checks that the project compiles for the simulator. It does not produce an installable app.

## Reminders

- Maintenance tasks: before the due date (you choose how far ahead), on the due date, and once more 3 days later if still open.
- Warranties: your chosen lead time, 1 week before, and on the last day.
- Reminders fire at the time of day you pick in the Reminders screen. Nothing is scheduled for the sample data.
- iOS allows 64 pending notifications per app, so HomeLedger schedules the soonest 60 and replans each time you change data or open the app.
- Marking a recurring task done moves it to its next date and reschedules the reminders.

## Bundle id

`com.homeledger.app` (set in `capacitor.config.json`, `android/app/build.gradle` and the Xcode project). Change it before publishing if you want your own id.
